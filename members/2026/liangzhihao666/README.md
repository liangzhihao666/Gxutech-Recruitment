## AI 辅助记录

### 1. 我遇到的问题

在完成技术组报名任务时，我不熟悉 Git 和 GitHub 的操作，执行 `git` 命令时遇到 `fatal: not a git repository` 报错，不知道当前目录在哪里，也不清楚接下来该敲什么命令。

### 2. 我是怎么向 AI 提问的

我把完整的报错信息发给了 AI，并说明我正在做 GitHub 报名任务，需要完成 Fork、分支、提交和 PR 流程，问它这个报错是什么意思、下一步应该怎么做。

### 3. AI 的回答有没有直接解决？

AI 解释了报错原因：当前目录不是 Git 仓库，需要用 `cd` 进入克隆下来的仓库目录。它给出了 `pwd`、`ls`、`cd` 等排查命令。我照着执行后，确认了自己所在的位置，并进入了正确的仓库目录。

### 4. 如果没有，我后来怎么继续处理？

按照 AI 给的方法进入仓库目录后，我继续执行创建分支、添加文件、提交和推送的命令。过程中又遇到其他问题，我会把新的报错继续发给 AI，或者自己搜索解决，最终完成了报名材料的提交。
